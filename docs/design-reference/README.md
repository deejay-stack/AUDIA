# AUDIA design reference

These original screenshots were retained from the previous `.design-review` folder:

- `store-light.png` and `store-dark.png`: storefront layout and theme.
- `auth-light-1440.png`: split account access layout.
- `admin-light-1440.png` and `admin-dark-390.png`: desktop and mobile administration.

Sample figures and demonstration credentials in the images are historical design content, not current application behavior. The application now renders account and administration data from its APIs. New forms and dialogs use the same colors, typography, borders, and spacing.

Old React source snapshots, temporary inspection scripts, and duplicate screenshots have been removed. New browser screenshots are optional test artifacts and belong in the ignored `test-results/` directory.
