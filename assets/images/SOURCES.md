# Uploaded catalog images

These images were supplied by the project owner. Original uploads are retained without edits.

`guitar_performance.jpg` is used on the authentication screen.

Additional owner-supplied images:

- `guitar_front.jpg`: public landing hero, storefront studio banner, and illustrative image fallback.
- `electric_studio.jpg`, `acoustic_studio.jpg`, `classical_studio.jpg`, `bass_studio.jpg`: matching family previews on the landing page and storefront.
- `electric_studio.jpg`: starter-rig promotional banner.
- `essentials.jpeg`: illustrative practice setup for the accessory pack (the pack description clarifies the image).

The guitar catalog uses `AUDIA Demo` and illustrative PHP prices, inventory and experience tiers for a school project. Ratings and review counts start at zero. Body/finish descriptions identify the pictured designs; filenames are not proof of brand, tonewood, electronics or physical specifications. Confirm these details before real commerce.

Product names are the public category codes; existing integer database IDs still link carts, orders and saved items. Numbering follows filename order within each category. Do not renumber existing products when adding a guitar.
